# Từ điển dữ liệu database nhân sự và tính lương
48 bảng gồm 47 bảng nghiệp vụ và 1 bảng khóa kỹ thuật. DATE nghiệp vụ không có phần giờ. valid_to là cận cuối loại trừ. TIMESTAMP nghiệp vụ dùng giờ Việt Nam; TIMESTAMP WITH TIME ZONE dùng cho thời điểm hệ thống.

## APP_USER
Tài khoản ứng dụng; API quản lý hash mật khẩu và xác thực

| Cột | Kiểu và ràng buộc | Ý nghĩa |
|---|---|---|
| user_id | `NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY (START WITH 1000) PRIMARY KEY` | Khóa tài khoản |
| username | `VARCHAR2(100 CHAR) NOT NULL` | Tên đăng nhập chuẩn hóa chữ thường |
| password_hash | `VARCHAR2(500 CHAR) NOT NULL` | Hash theo ASP.NET Identity; không lưu mật khẩu rõ |
| employee_id | `NUMBER` | Nhân viên gắn với tài khoản |
| is_active | `CHAR(1) DEFAULT 'Y' NOT NULL` | Cho phép sử dụng tài khoản |
| security_version | `NUMBER(10) DEFAULT 1 NOT NULL` | Tăng khi thu hồi phiên |
| created_at | `TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP NOT NULL` | Thời điểm tạo |

UNIQUE: username; employee_id
CHECK: is_active IN ('Y','N'); username = LOWER(TRIM(username)); security_version >= 1

FK employee_id → EMPLOYEE(employee_id)

| Cột | Kiểu và ràng buộc | Ý nghĩa |
|---|---|---|
| recon_line_id | `NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY (START WITH 1000) PRIMARY KEY` | recon_line_id |
| recon_import_id | `NUMBER NOT NULL` | recon_import_id |
| line_no | `NUMBER(8) NOT NULL` | line_no |
| payment_item_id | `NUMBER` | payment_item_id |
| transfer_reference | `VARCHAR2(80 CHAR) NOT NULL` | transfer_reference |
| bank_transaction_id | `VARCHAR2(100 CHAR)` | bank_transaction_id |
| reported_amount | `NUMBER(18,2) NOT NULL` | reported_amount |
| bank_status | `VARCHAR2(20 CHAR) NOT NULL` | bank_status |
| failure_reason | `VARCHAR2(1000 CHAR)` | failure_reason |
| match_status | `VARCHAR2(20 CHAR) DEFAULT 'UNMATCHED' NOT NULL` | match_status |

UNIQUE: recon_import_id,line_no
CHECK: reported_amount >= 0 AND line_no > 0; bank_status IN ('PROCESSING','SUCCEEDED','FAILED'); match_status IN ('UNMATCHED','MATCHED','AMOUNT_MISMATCH','CONFLICT'); bank_status <> 'SUCCEEDED' OR bank_transaction_id IS NOT NULL; bank_status <> 'FAILED' OR failure_reason IS NOT NULL

FK recon_import_id → BANK_RECON_IMPORT(recon_import_id)
FK payment_item_id → PAYMENT_ITEM(payment_item_id)

| Cột | Kiểu và ràng buộc | Ý nghĩa |
|---|---|---|
| payslip_id | `NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY (START WITH 1000) PRIMARY KEY` | payslip_id |
| result_id | `NUMBER NOT NULL` | result_id |
| issued_by | `NUMBER NOT NULL` | issued_by |
| issued_at | `TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP NOT NULL` | issued_at |
| document_id | `NUMBER` | document_id |

UNIQUE: result_id

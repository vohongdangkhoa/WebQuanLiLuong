| /\*           | Thư mục                                                                             | Dùng để làm gì? |
| ------------- | ----------------------------------------------------------------------------------- | --------------- |
| `Controllers` | Nhận yêu cầu từ React và trả lời. Bạn đã có `HealthController` ở đây.               |
| `Services`    | Điều phối các bước xử lý: kiểm tra thông tin, gọi phần lấy dữ liệu rồi trả kết quả. |
| `Data`        | Chứa code kết nối và làm việc với Oracle.                                           |
| `Contracts`   | Quy định dữ liệu gửi và nhận gồm những trường nào, chẳng hạn trường `status`.       | \*/             |
